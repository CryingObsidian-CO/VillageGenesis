# VillageGenesis 贸易路线与村庄互联特性研究

**研究日期:** 2026-03-26
**研究维度:** Features (特性)
**研究焦点:** 贸易路线系统与村庄互联机制

---

## 1. Table Stakes (基础必备特性)

> 缺失这些特性，用户会感觉系统不完整。复杂度较低，但必须实现。

### 1.1 贸易路线基础

| 特性 | 描述 | 复杂度 | 参考案例 |
|------|------|--------|----------|
| 路径定义 | 贸易路线必须有起点村庄和终点村庄 | 低 | Anno 系列 |
| 资源运输 | 定义运输什么物品类型和数量 | 低 | Civilization VI |
| 运输成本 | 基于距离、时间、资源消耗计算成本 | 中 | Cities: Skylines |
| 路线状态 | 活跃/暂停/中断状态管理 | 低 | Minecraft Create Mod |
| 运输频率 | 控制贸易发生的频率 | 低 | - |

### 1.2 村庄互联基础

| 特性 | 描述 | 复杂度 | 参考案例 |
|------|------|--------|----------|
| 村庄发现 | 自动发现或手动注册邻近村庄 | 低 | - |
| 距离计算 | 曼哈顿/欧几里得/路径距离计算 | 低 | - |
| 基础关系 | 村庄间友好/中立/敌对外交状态 | 低 | Civilization |
| 贸易协定 | 定义什么条件下可以建立贸易 | 中 | - |
| 资源互补性 | 判断村庄间是否有贸易价值 | 中 | Anno 1800 |

### 1.3 Table Stakes 实现优先级

```
Phase 1 (必须首先实现):
├── 村庄发现机制
├── 距离计算
├── 路径定义
└── 基础关系定义

Phase 2 (核心功能):
├── 资源运输
├── 运输成本
├── 贸易协定
└── 路线状态管理
```

## 2. Differentiators (差异化特性)

> 这些特性让系统从"能用"变成"有趣/有深度"，是竞争优势所在。

### 2.1 经济深度特性

| 特性 | 描述 | 复杂度 | 差异化价值 | 依赖 |
|------|------|--------|------------|------|
| 动态定价系统 | 基于供需关系自动调整贸易价格 | 高 | 模拟真实市场经济 | 资源运输 |
| 经济依赖链 | 村庄间形成供需依赖网络 | 高 | 模拟全球化经济 | 动态定价 |
| 贸易影响力 | 贸易量影响村庄发展速度和演进 | 中 | 正反馈循环，策略意义 | 经济依赖链 |
| 路线竞争机制 | 多条路线争夺相同资源/市场 | 中高 | 动态博弈，真实模拟 | 多节点网络 |

### 2.2 网络与可视化特性

| 特性 | 描述 | 复杂度 | 差异化价值 | 依赖 |
|------|------|--------|------------|------|
| 多节点贸易网络 | 路线可经过多个村庄中转 | 高 | 网络效应，策略深度 | 资源运输 |
| 贸易路线可视化 | 在游戏世界中显示路线和流量 | 中 | 直观反馈，沉浸感 | 路径定义 |
| 贸易统计面板 | 展示贸易量、利润、趋势 | 中 | 信息透明，决策支持 | 资源运输 |

### 2.3 动态与交互特性

| 特性 | 描述 | 复杂度 | 差异化价值 | 依赖 |
|------|------|--------|------------|------|
| 玩家干预点 | 玩家可投资/优化/建议路线 | 中 | 符合"影响者"定位 | 路线可视化 |
| 事件驱动中断 | 战争/灾害/资源枯竭影响贸易 | 中高 | 动态世界感 | 贸易协定 |
| 贸易历史记录 | 记录贸易事件供分析 | 低 | 数据驱动决策 | 资源运输 |

### 2.4 Differentiators 实现优先级

```
Phase 3 (核心差异化):
├── 动态定价系统 ★
├── 多节点贸易网络 ★
├── 玩家干预点 ★ (符合项目定位)
└── 贸易路线可视化

Phase 4 (增强差异化):
├── 经济依赖链
├── 贸易影响力
├── 事件驱动中断
└── 路线竞争机制

Phase 5 (锦上添花):
├── 贸易统计面板
└── 贸易历史记录
```

★ 标记为高优先级差异化特性

## 3. Anti-Features (明确不做的特性)

> 这些特性与项目核心价值冲突，或超出当前范围。

| 特性 | 排除原因 | 替代方案 |
|------|----------|----------|
| 玩家直接控制商队 | 与"影响者"定位冲突，玩家不是商人 | 玩家可投资/建议路线，由村民执行 |
| 实时物理运输模拟 | Minecraft 性能限制，开销过大 | 抽象的运输时间/成本计算 |
| 复杂贸易条约系统 | 属于外交系统，非贸易核心 | 简单的贸易协定，后续可扩展 |
| 货币投机系统 | 需要完整金融市场模拟，过于复杂 | 动态定价已足够 |
| 玩家作为贸易商角色 | PROJECT.md 明确排除 | 保持玩家"影响者"角色 |
| 贸易战机制 | 属于政治/军事系统 | 通过外交状态间接影响贸易 |
| 跨维度贸易 | 超出当前范围，增加复杂度 | 专注于主世界村庄互联 |
| 玩家自定义贸易物品 | 可能破坏经济平衡 | 使用数据驱动定义可交易物品 |

## 4. 特性依赖关系图

```
Level 0 (基础层) ─────────────────────────────────────────
├── 村庄发现机制
├── 距离计算
├── 路径定义
└── 基础关系定义
    │
    ▼
Level 1 (核心层) ─────────────────────────────────────────
├── 资源运输 ← 路径定义
├── 运输成本计算 ← 距离计算 + 路径定义
├── 贸易协定 ← 基础关系定义
├── 路线状态管理 ← 资源运输
└── 动态定价 ← 资源运输
    │
    ▼
Level 2 (增强层) ─────────────────────────────────────────
├── 多节点网络 ← 资源运输 + 运输成本
├── 经济依赖链 ← 动态定价
├── 路线可视化 ← 路径定义 + 资源运输
├── 玩家干预点 ← 路线可视化 + 贸易协定
└── 事件中断 ← 贸易协定 + 路线状态
    │
    ▼
Level 3 (高级层) ─────────────────────────────────────────
├── 路线竞争 ← 多节点网络
├── 贸易影响力 ← 经济依赖链
└── 贸易统计面板 ← 所有 Level 1-2 特性
```

## 5. 与现有系统的集成点

### 5.1 已有系统对接

| 现有系统 | 集成方式 | 影响范围 |
|----------|----------|----------|

## 7. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 性能问题（大量村庄互联） | 高 | 分区处理、异步计算、距离限制 |
| 经济平衡破坏 | 中 | 贸易税率、上限控制、测试验证 |
| 复杂度过高导致延期 | 中 | 分阶段实现、MVP 优先 |
| 与现有系统冲突 | 低 | 充分利用现有架构扩展点 |
